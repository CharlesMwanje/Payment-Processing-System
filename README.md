# Payment Processing System
 ## DESCRIPTION
A simple Java console application that processes customer payments, validates input, and applies discounts automatically.
 
## Features
 
- Process payments for multiple customers
- Input validation for payment amounts
- 10% discount on payments of UGX 100,000 and above
- Displays discount and final payable amount
- Menu-driven interface
 
## Technologies Used
 
- Java
- Scanner Class
- Loops ie. Do While,For,While
-  Conditional Statements if else if
- Tennary Operator
